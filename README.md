# homebrew-tap

Homebrew formulae for [victoraldir](https://github.com/victoraldir)'s tools.

## Usage

```bash
brew tap victoraldir/tap
brew install focal
```

## Formulae

| Formula | Description | Source |
| ------- | ----------- | ------ |
| `focal` | Convert photo sequences into timelapses by wrapping FFmpeg | [victoraldir/focal](https://github.com/victoraldir/focal) |

> Formulae in `Formula/` are generated and updated automatically by
> [GoReleaser](https://goreleaser.com) when a new version is released from the
> source repository. Manual edits will be overwritten on the next release.
